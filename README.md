# 🎬 Netflix Data Analysis

## Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Titles dataset using Python. The objective is to explore trends in Netflix's content library through data cleaning, visualization, and business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Analysis
- Movies vs TV Shows
- Content Ratings
- Release Year Trends
- Genre Analysis
- Movie Duration Distribution
- Content Added by Year & Month
- Top Directors

## Key Insights
- Movies make up most of Netflix's content.
- The United States has the highest number of titles.
- TV-MA is the most common content rating.
- Netflix experienced rapid content growth between 2017 and 2020.
- Most movies have durations between 90 and 120 minutes.

## Dataset
Netflix Titles Dataset (Kaggle)
